# 레퍼런스 분석: 80억 분의 1 (1in8b.life)

> 용도: Claude Code에서 '개발자 인생 시뮬레이션' PRD를 쓸 때 넣는 레퍼런스 컨텍스트
> 분석 방법: v0.5.41 베타를 실제로 플레이함(인도 농촌 여아, 0→41세, 수동 결정 후 자동 결정으로 전환)
> 분석일: 2026-10-08

---

## 1. 한 줄 정의

**실제 통계(141개국)를 확률 엔진으로 써서, 무작위로 태어난 한 사람의 일생을 30~90분 동안 실시간으로 살아 보게 하는 웹 내러티브 시뮬레이션.**
게임성(이기기)보다 **성찰과 공감**이 목적이다. "태어날 곳은 고를 수 없다. 선택은 삶을 바꾸지만 통계를 완전히 벗어나기는 어렵다"가 핵심 메시지.

## 2. 핵심 경험 루프

```
[랜딩: 실시간 출생/사망 카운터 + 국가 분포]
  → [설정: 시대 · 국가 추첨 기준 · 인생 길이 · 내 출생국(비교용)]
  → [출생 신고 카드: 무작위 배경 공개 + 내 나라와 비교 + '같은 1초에 태어난 4명']
  → [인생 진행 루프] ─ 시간 자동 흐름 (1년 ≈ 24초 @30분 모드, 배속 1~16×)
        ├ 올해의 초점 선택 (6세부터, 언제든 변경)
        ├ 랜덤 생활 이벤트 로그 (통계 기반, 출처 각주)
        ├ 중대 결정 모달 (진학·직업·결혼·출산·도덕적 선택 등)
        ├ 잠시 멈춤 (5·15·30·50·70세) → 성찰 질문 + 한 줄 기록
        └ 돈 쓰기 / 투자 (시간 정지 상태)
  → [사망: 생명표 기반 시점 + WHO/GBD 사망 원인]
  → [사망 기록 · 공유 카드 → 추모관 / 전생 기록]
```

## 3. 기능 분석 (PRD 항목 단위)

### 3.1 온보딩 / 설정

| 항목 | 내용 | 설계 의도 |
|---|---|---|
| 실시간 카운터 | "페이지를 연 뒤 태어난 아기 N명 / 세상을 떠난 사람 N명" | 첫 화면에서 스케일감과 몰입감 확보 |
| 시대 선택 | 지난 / 지금 / 다가올 세상 (다가올 세상 = UN 전망 + 불황·전쟁·AI·기후 확률) | 같은 엔진, 다른 파라미터 세트 |
| 추첨 기준 | 지금 태어나는 아기(출생아 수 가중) vs 지금 사는 80억 명(인구 가중) | 확률 가중치를 사용자에게 투명하게 보여 줌 |
| 인생 길이 | 30분 / 1시간 / 1시간 30분 | 세션 길이를 사용자가 고름 |
| 내 출생국(선택) | 고르면 계속 '나 vs 이 사람' 비교 | 개인화 → 감정 이입 |
| 콘텐츠 경고 | 무거운 장면 · 15세 이상 · 자살은 다루지 않음 | 윤리 가이드라인을 명시 |

### 3.2 캐릭터 생성 (출생 신고)
- 무작위로 정하는 값: 이름(국가별 이름 풀), 성별, 국가, 도시/농촌, 가정 형편(소득 5분위), 부모 나이·직업, 종교, 출생 순서
- 파생 지표: 기대수명, 5세 전 사망 확률, 1인당 GDP
- **비교 표**: 내 나라 vs 이 아이 나라 (기대수명, 아동사망률, 교육연수, GDP)
- **동시 출생자 4명**: 같은 1초에 태어난 다른 아이들. 끝까지 함께 진행되며 나이마다 상태가 보임(학교/일/결혼 등)
- 공유 가능한 '출생 카드'

### 3.3 메인 화면 구성 (진행 중)
1. **상단 바**: 나이, 연도, 이름, 진행 막대, 일시정지, 배속 1/2/4/8/16×, 다음 », ⋯ 메뉴(자동 결정, 음악, 생각 남기기, 의견, 가족과 삶 보기, 돈/투자, 나가기)
2. **픽셀아트 씬**: 거주지·가족 구성에 따라 바뀜 + 위치 캡션 ("인도 농촌 마을 · 시골집 · 부모님과 함께")
3. **스탯 바**: 건강 · 행복 · 지식 · 관계 (0–100) + 올해의 초점 칩
4. **인생 기록**: 연도별 이벤트 로그(최신순). 결정은 `▸ 결정: …`, 부정적 이벤트는 빨간색, 통계 각주는 초록색
5. **신원 기록**: 여권 MRZ 스타일 카드 (재미 요소)
6. **자산**: 순자산·연 소득을 PPP 달러와 '한국 체감 원화'로 함께 표시
7. **인생 지도**: 1칸 = 1년 그리드, 진할수록 행복했던 해, 기대수명 칸은 테두리로 표시
8. **생존 곡선**: 동년생 생존 비율 vs 세계 평균
9. **국가 통계 패널**: 20개 안팎의 지표 + 출처 목록

### 3.4 시스템 설계

**스탯 (4종, 0–100)**: 건강 / 행복 / 지식 / 관계. 결정과 초점이 이 값을 바꾸고, 진학 성공 같은 확률 판정에 들어간다.

**올해의 초점 (패시브 성장)**
- 공부(지식↑ 행복↓) · 친구·놀이(관계↑ 행복↑) · 집안 돕기(가족↑ 돈 조금) · 운동(건강↑) · 취미(행복↑ 취미 실력↑)
- 생애 단계가 바뀌면 시스템이 초점을 자동으로 바꿈 (예: 22세 '공부'→'가족·친구')

**중대 결정 (액티브 분기)** — 플레이에서 확인한 순서
| 나이 | 결정 | 선택지 예시 | 특징 |
|---|---|---|---|
| 2 | 기질 | 호기심/활발/다정/끈기 | 스탯 보정치를 숫자로 노출 |
| 7 | 좋아하는 것 | 축구/크리켓/춤 | 국가별 문화 반영 |
| 12 | 중학교 진학 | 계속 공부 / 일해서 가족 돕기 | "중학교 수료율 89%" 통계 박스 |
| 15 | 고등학교 | 진학 / 직업학교 / 취업 | 성공 확률 = 형편 × 성적 |
| 16 | 도덕적 선택 | 쓰러진 사람을 도울까 | 비용 대비 관계·행복 |
| 18 | 대입 | 입시 / 취업 / 해외 유학 | "붙을 가능성 반반쯤, 지식 70부터는 크게 달라지지 않음" |
| 19 | 전공 | 간호/교육/인문/공학/법학… | 전공 → 첫 직업 풀이 정해짐 |
| 20 | 중매 | 결혼 / 더 알아보기 / 거절 | 문화 맥락 반영(평균 초혼 연령) |
| 21 | 담배 | 거절 / 피워 본다 | 국가·성별 흡연율 |
| 22 | 졸업 후 | 취업 / 대학원 / 해외 대학원(비용 표시) | |
| 23 | 첫 직장 | 어부 · 농장 일꾼 · 소농 · 1년 더 구직 | **공학 학위가 있어도 농촌이면 비공식 일자리만 나옴** → 구조적 제약을 체감하게 함 |
| 26 | 이직 제안 | 연봉 비교 표시 | |
| 31 | 친척 돈 부탁 | 전부 / 일부 / 거절 | 모은 돈 기준 |
| 41 | 출산 | 4번째 아이 | 합계출산율·모성사망비 |

> 모든 결정 모달 구조: **제목 → 상황 설명 → 통계 박스(출처) → 2~5개 선택지(효과 힌트) → '자동으로 맡기기'**

**자동 결정 모드**: 결정 카드 아래 진행 막대 + "잠시 후 '…'(으)로 넘어가요 · 카드를 누르면 멈춰요". 보고만 싶은 사용자를 위한 장치.

**경제 시스템**: 국가 소득분포(지니계수)에서 소득을 뽑음 → 저축(예금 1~2% / 주식 평균 5% / 부동산 3.5%) → 소비처(외식·선물 = 관계↑, 취미 장비 = 취미 실력↑, 내 집 마련). 빚 이벤트도 있음("빚 116만 원 때문에 잠을 이루지 못했습니다").

**랜덤 이벤트**: 질병(설사병·독감), 가족 일화, 친구 사귀기/헤어짐, 성적, 경조사비. 일부에 WHO 등 출처 각주가 붙음.

**사망**: 국가·성별 생명표로 시점을, WHO·GBD 지역·연령 패턴으로 원인을 정함.

### 3.5 성찰 장치 (이 서비스만의 차별점)
- **잠시 멈춤 (5/15/30/50/70세)**: 통계 비교 + 동시 출생자 근황 + 열린 질문 (예: "이 아이가 꿈꿀 수 있는 미래와, 열다섯의 당신이 꿈꾸던 미래는 얼마나 달랐을까요?") → 한 줄 기록(선택), 기록은 인생 로그에 남음
- 마지막에 이 사람에게 한마디 남기기
- **추모관**: 끝까지 산 삶을 공개 아카이브로 보관. 누구나 촛불을 켜고 글을 남김(소셜 요소)
- **전생 기록 / 전생의 집**: 내가 산 삶들의 누적(평균 수명 등), 최근 10개 다시 보기 + 공유 카드

### 3.6 톤 & 비주얼
- 다크 테마, 세리프 헤드라인, 포인트 컬러는 핑크(#E06A8A 계열), 통계 박스는 틸 그린
- 픽셀아트 배경 + 문서/카드 메타포(출생 신고서, 여권 MRZ, 사망 기록)
- 문체: 담담한 2인칭·3인칭 서술, 판단하지 않음. 통계는 "약 N%"처럼 겸손하게 쓰고 "(추정)" 표기
- 잔잔한 음악은 선택(옵트인)
- 모바일 우선 단일 컬럼 (사이드 패널 폭에서도 깨지지 않음)

### 3.7 기술적으로 관찰한 점
- 단일 페이지 웹앱, 로그인 없음. 진행 상태는 localStorage에 저장("중간에 닫아도 이어서")
- 정적 자원: `/fonts/fonts.css`, `/era.js`(시대별 파라미터를 지연 로딩하는 것으로 보임), 이벤트 수집용 `/api/e`, Cloudflare 호스팅·분석
- 한국어/영어 i18n
- 버전 노출(v0.5.41 베타), 의견 보내기, 업데이트 노트 → 빠른 반복 운영
- 버그: '다가올 세상' 선택 시 "다른 시대의 자료를 불러오지 못했어요" 토스트가 뜨며 시작이 안 됨 → 시대 데이터 로드 실패 처리를 PRD에 넣어 둘 것

## 4. 잘된 점 / 아쉬운 점

**잘된 점**
- 데이터를 '보여주기'보다 **확률로 체험시키는** 구조 (진학 성공률, 일자리 풀)
- 결정마다 통계 박스로 맥락을 줘서 선택이 교육 콘텐츠가 됨
- '나 vs 이 사람', '동시 출생자 4명' 비교 프레임이 몰입을 끌어올림
- 자동 결정 + 배속 + 이어하기로 긴 세션의 부담을 덜어 줌

**아쉬운 점 (개발자 버전에서 개선할 기회)**
- 결정 밀도가 높아 20대에는 1~2년마다 모달이 뜸 → 피로감
- 스탯 4종의 효과가 결과에 얼마나 반영되는지 알기 어려움(피드백 루프 약함)
- 결정 결과의 인과가 약하게 드러남("이 선택 때문에 지금 이렇게 됐다"는 회고가 없음)
- 직업 이후의 커리어 성장(승진·전문성)은 깊이가 얕음

## 6. PRD 작성 전에 정할 질문

1. **목적**: 1in8b처럼 성찰·공감형인가, 커리어 설계를 돕는 교육형인가, 아니면 재미 위주의 게임인가?
2. **타깃**: 취준생·주니어(부트캠프 수강생)인가, 현업 개발자 전체인가?
3. **시뮬레이션 범위**: 출생부터 사망까지인가, 커리어(입문~은퇴)만인가?
4. **데이터 신뢰도**: 실제 통계를 근거로 둘 것인가(출처 표기 필수), 그럴듯한 가정으로 갈 것인가?
5. **MVP 범위**: 시대 1개 + 경로 3개 + 결정 15개 정도로 시작할지?
6. **한 판 길이**: 10분 / 30분?
7. **소셜**: 공유 카드·명예의 전당을 MVP에 넣을지?
